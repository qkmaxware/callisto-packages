Adding this Repository to Fedora

To use this RPM repository on your Fedora system, add it using the following command:

sudo dnf config-manager addrepo --from-repofile=https://qkmaxware.github.io/callisto-packages/callisto.repo

Or, manually create a repository configuration file:

sudo nano /etc/yum.repos.d/callisto.repo

Add the following content:

[callisto]
name=Callisto RPM Repository
baseurl=https://qkmaxware.github.io/callisto-packages/
enabled=1
gpgcheck=0

Then install packages with:

sudo dnf install package-name
