Callisto Package Repository

Search for packages in the Callisto OS custom package repository

Adding this Repository to Fedora

To use this repository on your Fedora system, add it using the following command:

sudo dnf config-manager addrepo --from-repofile=https://qkmaxware.github.io/callisto-packages/callisto.repo

Or, manually create a repository configuration file:

sudo nano /etc/yum.repos.d/callisto.repo

Add the following content:

[callisto]
name=Callisto RPM Repository
baseurl=https://qkmaxware.github.io/callisto-packages/rpm
enabled=1
gpgcheck=0
repo_gpgcheck=1
gpgkey=https://qkmaxware.github.io/callisto-packages/keys/publickey.gpg

Then install packages with:

sudo dnf install <package-name>

Adding this Repository to Debian/Ubuntu

First import the public signing key:

curl -fsSL https://qkmaxware.github.io/callisto-packages/keys/publickey.gpg | sudo gpg --dearmor -o /usr/share/keyrings/callisto-archive-keyring.gpg

To use this repository on your Debian based system, add it using the following command:

echo "deb [signed-by=/usr/share/keyrings/callisto-archive-keyring.gpg] https://qkmaxware.github.io/callisto-packages/deb ./" | sudo tee /etc/apt/sources.list.d/callisto.list

Update your package cache:

sudo apt update

Then install packages with:

sudo apt install <package-name>
